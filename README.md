# 信頼できる Genie エージェントの構築（Databricks Free Edition ハンズオン）

「テーブルを登録しただけの“素”の Genie エージェント」から出発し、**メタデータ整備・SQL 例・
結合・指示**を加えて精度を上げていく流れを、**ベンチマークの数値（BEFORE / AFTER）**で体験する
ハンズオンです。全編 Databricks **Free Edition** だけで完結します。

## このハンズオンで学べること

- Genie エージェントを作り、単純な質問は素でも当たる／業務ルールを含む質問は素だと外すことを体験する
- ベンチマーク（質問＋正解 SQL）で精度を **数値化** する（BEFORE スコア）
- **列コメント・シノニム（意味）／ SQL 例（ロジック）／結合（join）** を使い分けて Genie に教える
- 同じベンチマークで再採点し、**BEFORE → AFTER の精度向上を数値で** 確かめる

## 前提

- **Databricks Free Edition** アカウント（受講者は各自サインアップ／1 アカウント = 1 ワークスペース）
- Serverless SQL warehouse（Free Edition に標準で用意されています）
- サンプルデータ `samples.bakehouse`（全ワークスペース共通・追加準備は不要）

作業用のカタログ／スキーマ `workspace.reliable_agents` と必要なテーブルは、各モジュールの
セットアップが**冪等に自動構築**します（何度・誰が実行しても壊れません）。

## 進め方

`00` から `08` まで、上から順にノートブックを開いて実行してください（各モジュールの冒頭で
セットアップが走ります）。目安の所要時間は合計 2〜3 時間です。

| # | モジュール | 内容 |
|---|---|---|
| 00 | コース概要 | 全体像・前提・素→整備の弧 |
| 01 | Genie エージェント入門 | Genie One と Genie エージェントの違い |
| 02 | データ理解 (Bakehouse) | 5 テーブルと関係を SQL で概観 |
| 03 | Genie エージェントを作る | 素のエージェント作成（当たる質問／外す質問を体験） |
| 04 | ベンチマークで精度を測る | 6 問のベンチマークを登録し BEFORE スコアを測定 |
| 05 | 効果的なキュレーション設計 | 何を整備すると効くか（講義） |
| 06 | メタデータ整備 | 列コメント・シノニム・サンプル質問 |
| 07 | SQL ロジックと指示 | SQL 例・結合・指示を追記 → AFTER スコアで比較 |
| 08 | まとめと次の一歩 | 振り返り・実務展開・クリーンアップ |

## 補足

- ベンチマークの採点は**ライブの Genie（チャットモード）**を使うため、正答数は実行ごとに前後します
  （「結果は異なる場合があります」）。数値の絶対値より **BEFORE → AFTER の改善幅** に注目してください。
- もう一度最初から試したいときは、`08` のクリーンアップ（`cleanup=yes`）でエージェントと学習用
  スキーマを削除してから `02` / `03` に戻れます。
